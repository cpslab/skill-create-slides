# 架空作例の生成素材の来歴

3点とも2026-10-20にImageGenで制作した概念素材。撮影写真、実装済みの機器・アプリ、実験記録ではない。実研究の写真・UI・著者情報・値を複製した素材ではなく、架空の短い研究発表で画像配置を確かめるために用いる。

## 素材と用途

| ファイル | 内容・用途 | 入力での使用先 |
|---|---|---|
| [concept-device.png](concept-device.png) | 白いセンサー状の箱と低い灰色の機器を、植物のある明るい机に並べた写実的な概念画像。検知する役割を示す | `concept-materials` の「Sense the room」 |
| [concept-logger.png](concept-logger.png) | 教室の机上に、機器と接続されたノートPCを置いた写実的な概念画像。記録を確認する役割を示す | `concept-materials` の「Review the log」 |
| [concept-ui.png](concept-ui.png) | 緑と白の縦長の「Logging setup」概念画面。記録間隔、エクスポート、設定保存を示す。稼働するアプリのスクリーンショットではない | `interface` の操作説明 |

スライドでは「Generated concepts」「Concept interface」を可視表示し、実機や動作確認の証拠に見せない。UI内の間隔や文字は概念上の表示例であり、研究の実測値・検証済み仕様ではない。主要な操作説明はPPTXの編集可能な文字で画像外にも置く。チャートの値は別の入力JSONから作り、この画像から値を読み取って研究データへ使わない。

## 再生成・変更

通常のPPTX再生成にはこの3点をそのまま使う。画像自体を再生成・編集する場合もImageGenを使い、画像を参照入力として作風を揃える。白・淡い背景、緑系の差し色、読みやすい構図、実在製品のブランドや人物情報を入れないという方針を保つ。機器の実在性、UIの機能、測定値を生成画像から主張しない。

上記は画像を実際に確認した内容と用途の要旨であり、生成時の完全プロンプトの引用ではない。完全プロンプト・参照入力・変更履歴を追加するときは実際の実行記録を使い、後から推定した文章を当時のプロンプトとして記載しない。再生成後は新しいファイルのhash・採用先・生成日を記録し、最終PPTXも描画し直して確認する。
