* 利用範囲
このファイルは制作手順を学ぶために作った架空研究の教材である。
全ての数値は説明用の合成データであり、実測値・参加者データ・実在機器の性能ではない。
実際の発表へ研究事実として転用しない。

* 発表条件（架空）
- 発表先 :: 研究室の進捗報告
- 聴衆 :: センサー研究の専門外を含む学生
- 持ち時間 :: 4分
- 今回の到達点 :: 記録間隔の検討方法と、その検証範囲を共有する
- 研究の段階 :: 合成データによる処理の確認。実機・実室内での検証は未実施
- スタイル :: 16:9、白背景、濃色文字、強調色1色。所属ロゴは指定なし

* 問いと処理（架空）
- 問い :: 記録する点を減らすと、短時間の高い値がこの入力例から失われるか。
- 入力 :: 室内の二酸化炭素濃度を想定して人工的に作った13点の系列。
- 手順 :: 1分間隔の全13点と、0分・5分・10分の3点だけを保持した系列を比較する。
- 比較項目 :: 保持点数、保持された最大値、1000 ppmを超える記録点の有無。
- 1000 ppmの意味 :: 図の読み方を説明するための任意の閾値。安全基準・健康影響の判定ではない。
- 境界 :: 0〜12分の一つの合成系列と、一つの間引き開始時刻だけを扱う。
- 未実施 :: 実機測定、校正、電力測定、複数環境、別の開始時刻、人による認識の評価。

* この入力から計算できる結果（架空）
| 条件 | 保持点数 | 保持された最大値 [ppm] | 1000 ppmを超える記録点数 |
|------+----------+-------------------------+--------------------------|
| 1分間隔 | 13 | 1120 | 2 |
| 5分間隔 | 3 | 970 | 0 |

5分間隔で保持された最大値は、全13点の最大値より150 ppm低い。
点数の減少から消費電力の減少を推定しない。
閾値を超える記録点数を、閾値超過の継続時間や健康リスクと読み替えない。

* 根拠ラベル
- E1 :: 上記の合成入力表と間引き手順。
- E2 :: E1から計算した保持点数・最大値・閾値超過点数。
- P1 :: 今後の計画として、入力波形と開始時刻を変え、実機条件で確認する。
- U1 :: 記録間隔が実際の消費電力、絶対精度、利用者の理解へ与える影響は不明。
