* 段階と成果物
状態は「未着手・作成中・確認待ち・確定・要更新」を基本とする。途中再開で過去工程を調べない場合は「今回対象外」または「未確認」と記録し、未着手や確定を推測しない。
各工程のファイルは必要になった時に作り、既存の同等ファイルがあればそのパスを使う。

| 段階 | 状態 | 成果物のパス | 入力の版・更新日 | 確定の根拠 |

| 1 スタイル作成・適用 | 未着手 | | | |
| 2 企画書 | 未着手 | | | |
| 3 アウトライン | 未着手 | | | |
| 4 スライド構成と図 | 未着手 | | | |
| 5 完成イメージの画像化 | 未着手 | | | |
| 6 編集可能なPPTX制作 | 未着手 | | | |

* 必須レビューの記録
企画書、アウトライン、完成イメージは都度、使用者本人のレビューと現行版への了承を受ける。提示後は「確認待ち」で停止し、修正があれば修正版を再提示する。無回答や包括的な制作依頼を了承とみなさない。

| 対象 | 提示ファイル・版 | 提示日 | 使用者のレビュー内容 | 修正内容 | 了承の言葉・日付 | 次に進める工程 |
|------+------------------+--------+----------------------+----------+------------------+------------------|
| 企画書 | | | 未受領 | | 未了承 | アウトライン |
| アウトライン | | | 未受領 | | 未了承 | スライド構成と図 |
| 完成イメージ | | | 未受領 | | 未了承 | 編集可能なPPTX |

既存のレビューは現行版に対応する根拠を記録する。上流変更の影響を受けた対象は「要更新」として再レビューする。

* 未確定事項と次に確認すること
次工程に影響する未決事項だけを残す。解決後は決定記録へ統合する。
