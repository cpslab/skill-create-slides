#+title: 研究発表の入力票
#+startup: overview

* 使い方
この票は初回の情報整理に使う。提供資料から分かる欄は制作者が埋め、次工程に必要な不足だけを質問する。
既存の企画書や制作記録で同じ情報を管理している場合は、そのファイルを参照して重複管理しない。

* 発表条件
- 発表題目・発表者・所属 ::
- 発表先・発表日 ::
- 聴衆と前提知識 ::
- 聴衆が持ち帰ること ::
- 発表時間・質疑の時間（内数か別枠か） ::
- 言語・最大枚数・提出形式 ::
- 必須テンプレート・ロゴ・会場指定 ::
- 発表用アプリ・OS・投影環境 ::
- 今回作る範囲・途中から始める段階 ::

* 研究と正本
- 研究の種類（実証・装置システム・理論・計画など） ::
- 研究全体の目標と今回の対象範囲 ::
- 主に使う論文・実験記録・研究計画・版 ::
- 資料が矛盾するときに優先する正本 ::
- 確認できた成果と未実施の計画 ::
- 先行研究との比較資料と出典 ::
- 過去に受けた指摘と今回反映するもの ::

* 主要な主張と根拠
数値には単位・条件・標本数・対象期間を付ける。資料の所在を具体的な節・表・図・データへ対応させる。

| 主張ID | 発表したい主張 | 根拠の位置 | 条件・標本・単位 | 実測／解釈／計画 | 言える範囲・未確認 |
|--------+----------------+------------+-----------------+-----------------+------------------|

* 図と素材
- 実在する写真・画面・図表・データとその保存先 ::
- 各素材の利用条件・引用元・必要な加工 ::
- データ図の入力・処理・再生成方法 ::
- 使うスタイル（標準は中間発表型CPS／別指定があれば記載） ::
- 表紙の選択（FIT2026型／中間発表型）と選択根拠 ::
- 表紙用の写真、または背景動画・静止ポスターと保存先 ::
- 動画表紙の再生環境・自動再生・ループ・無音の確認 ::
- キーカラー（CPSで未指定ならボタニカ） ::
- 既存PPTXの現物と保持する手動編集 ::
- 編集したい範囲（本文・模式図・表・チャートの値等） ::

* 制作環境
- スキルの版・制作ツール・モデル（取得できる範囲） ::
- 画像生成・PPTX編集・レンダーの利用可否 ::
- 指定フォントの存在・代替時の差 ::
- 保存先・共有先の指定 ::
- 未確定事項と次に必要な判断 ::
