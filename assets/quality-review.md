## 判定

判定は pass（合格）／error（不具合）／review_required（判断待ち）／unverified（未検証）／not_applicable（理由付き対象外）。根拠には該当ファイル・ページを記す。
平均点で相殺せず、必要な項目の修正を済ませる。未検証は合格に含めない。

| 観点 | 判定 | 根拠・対象ページ | 必要な修正・未検証の理由 |
|------|------|------------------|--------------------------|
| 主張と根拠・数値の一致 | | | |
| 目的→方法→結果→結論の対応 | | | |
| MBとスライド・版・順序・枚数 | | | |
| 持ち時間と章の配分 | | | |
| スタイル・ロゴ・色の一致 | | | |
| 採用構成の章・目次型・章扉・本編終了・補足・サマリ位置 | | | |
| 選んだ表紙型・素材・本文との独立 | | | |
| 全ページの文字・図・余白 | | | |
| 図の矢印・比較・分岐の意味 | | | |
| 指定要素の編集可能性 | | | |
| ZIP・XML・画像・リンクの整合 | | | |
| 出典・素材と生成物の来歴 | | | |

## 必須レビューの確認

- 企画書の現行版・使用者レビュー・了承の記録：未確認
- アウトラインの現行版・使用者レビュー・了承の記録：未確認
- 完成イメージ画像の現行版・使用者レビュー・了承の記録：未確認
- 修正後の再レビュー・未了承箇所：未確認

- 目次の存在・本文の章順との一致：未確認
- 表紙を含む全スライドのページ番号・連番・可読性：未確認
- 構成ファイル内の目次・全章扉の個別仕様（番号・内容・配置・素材）：未確認
- 完成イメージが全ページを含む1枚の画像であること・枚数・順序・欠落／重複：未確認
- 左右の小見出し・引用番号と下部参考文献の対応：未確認
- 採用したサマリ位置・概要・著者・指定連絡先／省略の確認：未確認
- 実研究制作／内部試験とレビューの適用範囲：未確認

## 発表用メモ

- 補足・限定の必要箇所をメモへ記録：未確認
