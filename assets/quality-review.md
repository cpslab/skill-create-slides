# 研究発表の品質確認

## 対象

- 確認日・確認者（自己確認／別担当）：
- 成果物・版・ファイルhash：
- 参照した論文・データ・構成・スタイルの版：
- スキルの版・制作環境・フォント：
- 今回検証する段階：

## 判定

判定は pass（合格）／error（不具合）／review_required（判断待ち）／unverified（未検証）／not_applicable（理由付き対象外）。根拠には該当ファイル・ページを記す。
平均点で相殺せず、必要な項目の修正を済ませる。未検証は合格に含めない。

| 観点 | 判定 | 根拠・対象ページ | 必要な修正・未検証の理由 |
|------|------|------------------|--------------------------|
| 主張と根拠・数値の一致（該当時は対象・全体／部分集団・集約単位・期間） | | | |
| 最終PPTXの可視テキストを表示順に読み、文体欄・ページの役割・意味の保持を確認（字句一致だけで判定しない） | | | |
| 目的→方法→結果→結論の対応 | | | |
| MBとスライド・版・順序・枚数 | | | |
| 持ち時間と章の配分 | | | |
| スタイル・ロゴ・色の一致 | | | |
| 採用構成の章・目次型・章扉・本編終了・補足・サマリ位置 | | | |
| 選んだ表紙型・素材・本文との独立 | | | |
| 全ページの文字・図・余白 | | | |
| デッキ全体に写真1つ以上（必須） | | | |
| 本編に研究全体の概要図・アーキテクチャ図1つ以上。主要要素・役割・関係や流れ・対象範囲が分かる（必須） | | | |
| 本文枚数に応じたイラストの標準量・掲載ページ・説明目的・調整理由（再掲・部品は加算しない） | | | |
| 図の目的に必要な役割・入出力と、矢印・比較・分岐の意味 | | | |
| 指定要素の編集可能性 | | | |
| ZIP・XML・画像・リンクの整合 | | | |
| 出典・素材と生成物の来歴（制作元・派生画像・PPTXの編集可能範囲） | | | |
| 手動編集の保持 | | | |
| 対象アプリでの表示・編集・再生 | | | |

グラフの採用は推奨であり、上表の必須判定とは分ける。

- 表だけでなくグラフを検討した結果・採用ページと正本データ（適したデータがなければ不要）：
- 文体を参照した資料・メモリの範囲、適用した特徴と修正箇所：

文体は [確認観点](../references/writing-style.md) に沿って具体的に記録する。メモリを参照できないことや文体の完全一致を理由に新たな承認を要求せず、既存のレビュー内で調整する。

## 必須レビューの確認

- 企画書の現行版・使用者レビュー・了承の記録：未確認
- アウトラインの現行版・使用者レビュー・了承の記録：未確認
- 完成イメージ画像の現行版・使用者レビュー・了承の記録：未確認
- 修正後の再レビュー・未了承箇所：未確認

- 目次の存在・本文の章順との一致：未確認
- 表紙を含む全スライドのページ番号・連番・可読性：未確認
- 構成ファイル内の目次・全章扉の個別仕様（番号・内容・配置・素材）：未確認
- 完成イメージが全ページを含む1枚の画像であること・枚数・順序・欠落／重複：未確認
- 左右の小見出し・引用番号と下部参考文献の対応：未確認
- 採用したサマリ位置・概要・著者・指定連絡先／省略の確認：未確認
- 実研究制作／内部試験とレビューの適用範囲：未確認

## 発表用メモ

- 補足・限定の必要箇所をメモへ記録：未確認
- 出力PPTXとメモの親ディレクトリが一致：未確認
- 最終ページ番号・スライドID・主張との対応：未確認
- 利用者の追記の保持と納品時の場所案内：未確認
- 主張・図ラベルを正確にし、理解を変える条件は画面にも残した：未確認
- 発話補足と発表・質疑に必要な詳細根拠をメモへ残し、制作TODOを制作確認記録へ分離：未確認
- PPTX内ノートと外部メモの正規化結果・番号・ID・順序・記述の照合：未確認
- 最終PPTX・メモ・入力のhashと検査結果、意味確認の解消記録：未確認
- 自動生成範囲のhash不一致・不明時に原本を保持し、候補との差分を統合：未確認

メモが不要な場合は理由付き対象外とし、すべてのページに欄を作らない。機械検査の一致と、元資料に照らした意味の確認を区別する。

## 最終受入

最終PPTXのhashを全ての証拠へ対応させ、メモがある場合はメモ・入力のhashも検査結果へ結び付ける。必須項目に error・未解決 review_required・unverified が残れば検証済み完成としない。
