#+title: 研究発表の品質確認

* 対象
- 確認日・確認者（自己確認／別担当） ::
- 成果物・版・ファイルhash ::
- 参照した論文・データ・構成・スタイルの版 ::
- スキルの版・制作環境・フォント ::
- 今回検証する段階 ::

* 判定
判定は「合格・修正必要・未検証・対象外」。根拠には該当ファイル・ページを記す。
平均点で相殺せず、必要な項目の修正を済ませる。未検証は合格に含めない。

| 観点 | 判定 | 根拠・対象ページ | 必要な修正・未検証の理由 |
|------+------|------------------|--------------------------|
| 主張と根拠・数値の一致 | | | |
| 目的→方法→結果→結論の対応 | | | |
| MBとスライド・版・順序・枚数 | | | |
| 持ち時間と章の配分 | | | |
| スタイル・ロゴ・色の一致 | | | |
| 全ページの文字・図・余白 | | | |
| 図の矢印・比較・分岐の意味 | | | |
| 指定要素の編集可能性 | | | |
| ZIP・XML・画像・リンクの整合 | | | |
| 出典・素材と生成物の来歴 | | | |
| 手動編集の保持 | | | |
| 対象アプリでの表示・編集・再生 | | | |

* 修正と再確認
- 見つかった問題と修正したページ ::
- 再確認した範囲・方法 ::
- 残る利用上の制約 ::
- 利用者の内容確認・未確定の判断 ::
