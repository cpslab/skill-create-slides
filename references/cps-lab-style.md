# CPS LAB：中間発表型の構成・デザイン

## 適用と表紙の選択

このスキルの標準は、中間発表で用いた構成と本文デザイン。表紙だけ次の2種類から選ぶ。表紙の違いで本文・目次・章扉・まとめは変えない。ユーザーが明示した別テンプレートや修正範囲がある場合は、その指定を優先する。

| `COVER_STYLE` | 表示名 | 素材 | レイアウト |
|---|---|---|---|
| `fit` | FIT2026型 | 今回の研究対象・実機の写真 | 白背景、中央の題目帯、所属・発表者の灰色帯、右下の写真、共通フッター |
| `midterm` | 中間発表型 | 今回の研究を示す背景動画と静止ポスター | 全画面動画、中央揃えの白文字、フッター・ロゴなし |

初回に利用者の指定・現物を読み、選択がなければこの2択だけを確認する。本文の標準は質問し直さない。未回答時も企画書・本文構成を進められる。写真や動画が未提供なら必要な素材を具体的に伝え、無断で別の型へ変更しない。動画型を静止画にする場合は、その変更を利用者と決めて記録する。

## 標準の構成

表紙 → 必要に応じた研究の現在地 → 画像付き目次 → 01研究のねらい → 02しくみと評価方法 → 03ここまでの結果 → 04今後の展望 → まとめ → 補足。

- 第1章では研究のねらい・問題・前提・今回の範囲を示し、関連研究を個別に紹介した後、同じ比較軸の表へまとめる。
- 各章の入口には章番号・章名・短い案内文を置く上部型の章扉を使う。関連研究に追加の区切りが必要なら同じ型を使う。
- 結果の解釈と限界は該当結果の近くへ置き、今後の具体的な設計・検証へ接続する。独立した議論章を自動追加しない。
- 目次とまとめの章名・順序を揃える。発表実績のない研究に学会名・採択実績を捏造しない。
- 枚数、研究名、関連研究名、図の数は今回の資料から決める。過去の46枚や特定の研究内容はテンプレートではない。

## 色・文字・寸法

| トークン | 既定値 | 用途 |
|---|---|---|
| `KEY_COLOR_NAME` | ボタニカ | 下表から選ぶ発表単位の色名 |
| `KEY_COLOR` | `#9BBB59` | 強調面・線・注目系列 |
| `ON_KEY_COLOR` | `#000000` | キーカラー面の文字 |
| `BACKGROUND` | `#FFFFFF` | 本文・目次・章扉・まとめ |
| `TEXT` | `#17202A` | 本文・見出し |
| `SUBTEXT` | `#59636E` | 補足・出典 |
| `KEY_COLOR_TINT` | `#EFF5E4` | ボタニカの場合の薄い面。他の色は白へ85–92%混ぜる |
| `NEUTRAL_BAND` | `#999999` | FIT型表紙の所属・発表者帯 |

| 色名 | `KEY_COLOR` | `ON_KEY_COLOR` |
|---|---|---|
| アイリス | `#8064A2` | `#FFFFFF` |
| kiMera | `#FACADF` | `#000000` |
| オレンジ | `#F79646` | `#000000` |
| シチリア | `#4BACC6` | `#000000` |
| ボタニカ | `#9BBB59` | `#000000` |
| ボルドー | `#C0504D` | `#FFFFFF` |

色名が未指定なら質問せずボタニカを使う。表にない指定はユーザーの明示変更として扱い、曖昧な場合だけ確認する。白地の強調文字は濃い `TEXT` と太字を基本とし、薄い緑の文字へ一律変更しない。系列は記号・線種・ラベルでも区別し、図固有の意味色は保つ。

16:9、基準10×5.625 inch（720×405 pt）。13.333×7.5 inchでは位置・寸法・文字サイズを4/3倍する。描画APIのpxとptを混同しない（96 px = 72 pt）。フォントはNoto Sans JP、代替はSawarabi Gothic。代替使用は記録する。ページ番号はArial。細いウェイト、強い影、立体・光彩・装飾的なカード列は使わない。

| 要素 | 基準サイズでの文字 | 配置・量 |
|---|---|---|
| 表紙題目 | 28–32 pt、太字 | 2行以内、中央揃え |
| 表紙情報 | 16–18 pt | 発表先、日付、所属、発表者 |
| 通常タイトル | 26–30 pt、太字 | 原則1行、左揃え |
| 主メッセージ | 22–26 pt、太字 | 最大2行、左揃え |
| 章扉の章名 | 36–40 pt、太字 | 上部のキーカラー帯に章番号と並べる |
| 章扉の案内文 | 22–26 pt | 章名の下に短く1文 |
| 本文 | 18–22 pt | 左揃え、長文を置かない |
| 図ラベル | 14–18 pt | 対象に寄せ、図とともに読める大きさ |
| 重要条件・主要数値 | 18–22 pt | 小さい出典文字へ追い込まない |
| 出典 | 8–10 pt | 図の直下または本文の最下部 |
| ページ番号 | 14 pt | 右下 |

収まらないときは本文を縮めず、短文化・補足への移動・MBの分割を検討する。本文18 pt、図ラベル14 ptを下回らない。

## 本文のグリッド

座標・寸法はinch。題名を話題、主メッセージをその答えとして上部に置く。章名や内部MB番号を追加ラベルとして重ねない。

| 領域 | x・y・幅・高さ | 役割 |
|---|---|---|
| タイトル | 0.50・0.12・9.00・0.43 | 話題が分かる短い題名 |
| 主メッセージ | 0.50・0.68・9.00・0.76 | 目的・結論を1文で示す |
| 主図・写真 | 0.50・1.60・9.00・2.92 | 下部の主役。図と写真の高さを揃える |
| 重要条件 | 0.50・4.58・9.00・0.34 | 実測／模式例／計画、単位、重要な限定 |
| 短い出典 | 0.50・4.94・9.00 | 本文とフッターをまたがない |
| フッター | y=5.045以降 | 下端線・左下ロゴ・右下ページ番号 |

関連するラベルは対象へ寄せ、無関係な要素には0.18–0.25 inch程度の間隔を取る。正確な模式図は意味単位で編集可能にし、比較を通信・因果の矢印で描かない。実験図は正本データから作り、軸・単位・標本・条件・誤差表現を確認する。実機・評価写真は今回の正本素材を使い、実測値を示す画像をImageGenで生成しない。

## 目次・章扉・関連研究・まとめ

### 画像付き2×2目次

上部に「目次」と短い全体案内、下部に4章を2×2で置く。左上01、右上02、左下03、右下04。各領域は章番号・章名と、内容に対応する画像1枚。枠・影・角丸カードで囲わず、中央の薄い縦横線と余白で区切る。実物写真、評価場面、結果図、計画を示す概念図などを使い分け、計画画像には画像外へ「計画」と明記する。未提供の実証素材は生成で代用しない。

### 上部型の章扉

上部のキーカラー帯に章番号と目次と同じ章名、その下に短い案内文を置く。基準の帯は左0.50、上1.06、幅8.50、高さ0.90 inch。章名の左は0.73、案内文は左0.75・上2.31 inchを目安とする。帯上の文字は選択色の `ON_KEY_COLOR` を使う。右上ロゴを保ち、下部は広い白い余白にする。下寄りの色付き章名帯、左下ロゴ、下端線は置かない。ページ番号は右下へ置く。

### 関連研究

個別紹介では上部に研究名と要点、下部に引用図と自分の研究との違いを置く。研究名の下へ本文の細字を大量に貼らない。最後の比較表は比較項目を行、対象研究を列にし、何を比較しているかを見出しに書く。未実装の項目は「計画」として実装済みから区別する。短い出典をスライド上、詳細をノートへ置く。

### 縦4行のまとめ

上部は通常ページと同じ「まとめ」と主メッセージ。下部は左に章番号・章名、右に1〜2行の要約を置く4行。順序は目次・章扉と同じ。目安は左幅2.91 inch、間隔0.19 inch、右幅5.90 inch。行間には余白と薄い灰色の区切り線を置き、確認済みの結果と将来計画を文章で区別する。下部の大きな結論帯や角丸ボックスを足さない。通常フッターを使う。

## 表紙A：FIT2026型（fit）

- 白背景。左上に今回の発表先・日付などを置く。元のFITの名称・日時・発表者を残さない。
- 中央付近のキーカラー帯は左0.75、上1.55、幅8.50、高さ1.21 inchを目安にする。正式題目を `ON_KEY_COLOR` で2行以内、中央揃え。
- 下側の左に所属と発表者の灰色帯を2本、右に今回の研究対象・実機の写真1枚を置く。帯と写真を重ねず、写真の縦横比を守る。寸法は所属名と写真に合わせて調整する。
- 写真は対象を見せるために使い、通信波などを飾りとして足さない。写真が不要・用意できない場合は省略の判断を記録し、架空の実機を生成しない。
- 共通フッター、左下ロゴ、右下ページ番号を使う。

## 表紙B：中間発表型（midterm）

- 利用者が提供・指定した動画を16:9全画面に置く。背景の上に題目、所属、発表者などを中央揃えの白文字で重ねる。元の研究名や個人情報は引き継がない。
- 題目を中央より上、所属・発表者をその下へ置く。発表先・日付は上側。本文用の題目帯、灰色の所属帯、ロゴ、下端線、ページ番号は置かない。
- 原本を保持し、無音の派生動画を作る。元の中間表紙の彩度90%・黒30%混合を初期値として、全尺で白文字を読めるよう調整する。色調の数値を映像ごとに無条件で固定しない。
- H.264 MP4を優先して埋め込み、同じ映像の静止ポスターを用意する。縦横比と再生速度を維持する。
- 表示時の自動再生、表紙中のループ、次ページへの遷移時停止、操作バー非表示を目標とし、対象アプリで確認する。静止画レンダーだけで再生検証済みと書かない。
- 動画を使えない環境では、静止ポスターへの変更を利用者と決める。GIF化や別サービスへのアップロードを勝手に行わない。
- 同梱の表紙見本は、未提供動画の配置を示す静止レイアウトであり、動画入り成果物ではない。

## ロゴ・フッター

正本は [NewmajimeModeLogoSmall.png](../assets/NewmajimeModeLogoSmall.png)、438×123 px。変形、切り抜き、再着色、透明度変更、影付けをしない。周囲には少なくとも0.15 inchの余白を保つ。

| 種類 | ロゴ・線・ページ番号 |
|---|---|
| 本文・目次・まとめ・補足・FIT型表紙 | ロゴ：左0.321・上5.253・幅0.895 inch。下端線：上5.045・高さ0.059 inch。ページ番号：右下 |
| 章扉 | ロゴ：左8.418・上0.241・幅1.211 inch。左下ロゴと下端線なし。ページ番号は右下 |
| 中間型表紙 | ロゴ・下端線・ページ番号なし |

出典はフッターのロゴやページ番号へ重ねない。通常ページと章扉のロゴを1枚へ重複配置しない。

## 最終確認

- 表紙型を記録し、必要な写真／動画とポスターが揃っている。
- 表紙の選択にかかわらず、中間発表型の4章・目次・上部章扉・縦4行まとめを使っている。
- 目次・章扉・まとめの章名と順序が一致する。短時間版の省略は記録している。
- 本文のタイトル、主メッセージ、図、条件、出典の読み順と文字階層が揃っている。
- 実測・模式例・計画の区別、出典、数値、図の意味を確認した。
- 最終PPTXの全ページを画像化して個別に見た。動画の再生確認は別に記録した。
