# CPS LAB：構成プロファイルと共通の視覚仕様

## 適用と表紙の選択

従来型の `cps-midterm` と、短い研究発表の `cps-workshop` を用意する。研究入力とは独立した構成と視覚の初期値であり、章数・枚数・内容は採用構成で決める。表紙は両プロファイルから独立して次の2種類から選び、表紙の違いで本文・目次・章扉・まとめを変えない。

| `COVER_STYLE` | 表示名 | 素材 | レイアウト |
|---|---|---|---|
| `type-a` | 表紙タイプA | 必要に応じて今回の研究対象・実機の写真 | 白背景、中央の題目帯、所属・発表者の灰色帯、右下の写真、共通フッター |
| `type-b` | 表紙タイプB | 今回の研究を示す背景動画と静止ポスター | 全画面動画、中央揃えの白文字、ロゴ・下端線なし、右下にページ番号 |

表示名は「表紙タイプA／表紙タイプB」、制作記録の `COVER_STYLE` は `type-a`／`type-b` に統一する。旧制作記録の `fit` は `type-a`、`midterm` は `type-b` として読み替え、選択済みなら聞き直さない。旧名は新しい選択肢として使用者へ提示しない。

初回に利用者の指定・現物を読み、選択がなければこの2択だけを確認する。本文の標準は質問し直さない。未回答時も企画書・本文構成を進められる。表紙に写真を置かない場合はその判断を記録し、別ページに写真を置いて[デッキ全体の素材要件](../SKILL.md#写真と研究全体の概要図は必須イラストは標準量グラフは推奨)を満たす。必要な写真や動画が未提供なら必要な素材を具体的に伝え、無断で別の型へ変更しない。動画型を静止画にする場合は、その変更を利用者と決めて記録する。

## 任意の参考スライドで細部を調整する

参考スライドはCPS LAB全体を置き換えるテンプレートではなく、細部の調整に使う。実際の参照ページを見て、次の区別で適用する。

| 維持するCPS LABの基本 | 参考に寄せられる細部 |
|---|---|
| 16:9、白を基調とする本文、選択済みの表紙型 | 各ページ内の余白、整列、文章と図の占有比率 |
| 採用した構成、必須目次・ページ番号、選択した章扉・本編終了・補足の順序 | 文字の組み方、改行、行間、太さ、強調、見出しと本文のサイズ比 |
| 正本ロゴと所定の扱い、題名と本文・図表の明確な情報階層 | 補助色、淡色面、文字色、図表の系列色、強調色の使い分け |
| Noto Sans JPを基本とする文字体系、十分な可読性、編集可能性 | 図・写真の大きさ、位置、密度、注釈の置き方 |

キーカラーはCPS LABの色体系を軸に、参考の色相・明度・彩度・配色比率を取り入れる。本文全面を暗色にする、別組織のロゴへ交換する等の変更は、この細部調整には含めない。数値で定めた文字サイズ・図の寸法・配置は標準値とし、参考に合わせて調整する場合は今回の採用値と理由を記録する。読めないほどの小文字や低コントラストは模倣しない。

`style.md` に「参考資料のパス／URL・ページ」「寄せたい特徴」「維持するCPS要素」「採用した細部・具体的な値」「適用するスライド」を記録し、`slide-structure.md` の各ページ仕様へ反映する。複数の参考がある場合は対象ページや用途ごとに対応を決め、全体の色と文字階層を揃える。優先する参考が判断できない場合だけ使用者へ確認する。

## 構成の選択

構成の正本は [planning.md](planning.md)。視覚設定の機械可読な初期値は [cps-midterm.json](../assets/profiles/cps-midterm.json) と [cps-workshop.json](../assets/profiles/cps-workshop.json)。共通CPSの色対応は下表を正本とする。

| プロファイル | 適した発表 | 構成の初期値 |
|---|---|---|
| `cps-midterm` | 研究の進捗を体系的に示す中間発表 | 表紙 → 必要な現在地 → 画像付き2×2目次 → 4章と上部章扉 → 縦4行まとめ → 必要な補足 → 最終サマリ |
| `cps-workshop` | 時間を絞り、問い・提案・知見・議論へつなぐ研究発表 | 表紙 → 縦目次 → 可変数の章（章扉なしを選べる） → 本編サマリ → 必要な補足 |

本編終了とデッキ最終表示は別の設定とする。短い発表で補足後にサマリを再掲する場合は構成へ追加する。結果・実装のない研究は計画として構成し、既定の章を埋めるために成果を創作しない。表紙型、章数、総枚数は互いから推測しない。

## 色・文字・寸法

| トークン | 既定値 | 用途 |
|---|---|---|
| `KEY_COLOR_NAME` | ボタニカ | 下表から選ぶ発表単位の色名 |
| `KEY_COLOR` | `#9BBB59` | メインカラー：表紙・章扉の帯、主要な面・線 |
| `ACCENT_COLOR` | `#38761D` | 独立したアクセント：重要語・主要数値・注目点・強調線 |
| `ON_ACCENT_COLOR` | `#FFFFFF` | アクセント面に載せる文字 |
| `ON_KEY_COLOR` | `#000000` | キーカラー面の文字 |
| `BACKGROUND` | `#FFFFFF` | 本文・目次・章扉・まとめ |
| `TEXT` | `#17202A` | 本文・見出し |
| `SUBTEXT` | `#59636E` | 補足・出典 |
| `KEY_COLOR_TINT` | `#EFF5E4` | ボタニカの場合の薄い面。他の色は白へ85–92%混ぜる |
| `NEUTRAL_BAND` | `#999999` | 表紙タイプAの所属・発表者帯 |

| 色名 | メイン `KEY_COLOR` | `ON_KEY_COLOR` | アクセント `ACCENT_COLOR` | `ON_ACCENT_COLOR` |
|---|---|---|---|---|
| アイリス | `#8064A2` | `#FFFFFF` | `#543477` | `#FFFFFF` |
| kiMera | `#FACADF` | `#000000` | `#A61C60` | `#FFFFFF` |
| オレンジ | `#F79646` | `#000000` | `#B45F06` | `#FFFFFF` |
| シチリア | `#4BACC6` | `#000000` | `#165F73` | `#FFFFFF` |
| ボタニカ | `#9BBB59` | `#000000` | `#38761D` | `#FFFFFF` |
| ボルドー | `#C0504D` | `#FFFFFF` | `#8B2523` | `#FFFFFF` |

各色の見た目は [配色見本](palette-reference.md) とREADMEの各色1枚の画像で比較できる。

ベースカラーは白 `BACKGROUND`、メインは `KEY_COLOR`、アクセントはそれと異なる `ACCENT_COLOR` として常に定義する。ボタニカのアクセントは使用者指定の `#38761D`。他の5色は、その方針にならいメインより濃い同系色としてこのスキル用に設定したもので、元のCPS LAB資料から抽出した色ではない。

メインはまとまりを作る帯・面・線、アクセントは視線を集めたい重要語・数値・図の注目点に絞って使う。本文全体をアクセント色にせず、通常文字は `TEXT`、補足は `SUBTEXT` とする。アクセントの定義は必須だが、全ページへの強制使用や固定の面積比率は設けない。白背景上のアクセント文字とアクセント面上の文字はコントラストを確認し、淡いメイン面上では通常の濃色文字を基本にする。

`style.md` に3色のHEX値と用途を記録する。標準6色では上表を使い、別配色や参考資料による明示的な配色変更でも独立したアクセントを必ず選び、採用値・用途・可読性を記録して完成イメージでレビューする。

色名が未指定なら質問せずボタニカを使う。表にない指定はユーザーの明示変更として扱い、曖昧な場合だけ確認する。白地の強調文字には `ACCENT_COLOR` または濃い `TEXT` と太字を使い、薄いメインカラーの文字へ一律変更しない。系列は記号・線種・ラベルでも区別し、図固有の意味色は保つ。

16:9、基準10×5.625 inch（720×405 pt）。13.333×7.5 inchでは位置・寸法・文字サイズを4/3倍する。描画APIのpxとptを混同しない（96 px = 72 pt）。フォントはNoto Sans JP、代替はSawarabi Gothic。代替使用は記録する。共通生成器のページ番号も採用プロファイルのフォントを使う。従来の9枚教材は既存のArial番号を保持する。細いウェイト、強い影、立体・光彩・装飾的なカード列は使わない。

以下は `cps-midterm` の10 inch基準。`cps-workshop` は後述の役割別初期値を使う。

| 要素 | 基準サイズでの文字 | 配置・量 |
|---|---|---|
| 表紙題目 | 28–32 pt、太字 | 2行以内、中央揃え |
| 表紙情報 | 16–18 pt | 発表先、日付、所属、発表者 |
| 通常タイトル | 26–30 pt、太字 | 原則1行、左揃え |
| 主メッセージ | 22–26 pt、太字 | 最大2行、左揃え |
| 章扉の章名 | 36–40 pt、太字 | 上部のキーカラー帯に章番号と並べる |
| 章扉の案内文 | 22–26 pt | 章名の下に短く1文 |
| 本文 | 18–22 pt | 左揃え、長文を置かない |
| 図ラベル | 14–18 pt | 対象に寄せ、図とともに読める大きさ |
| 重要条件・主要数値 | 18–22 pt | 小さい出典文字へ追い込まない |
| 出典 | 8–10 pt | 図の直下または本文の最下部 |
| ページ番号 | 14 pt | 右下 |

収まらないときは、意味の重複の短文化 → レイアウト変更 → 列幅・行高・改行の調整 → 詳細の補足移動 → 主題の分割の順で直す。`cps-midterm` は本文18 pt・図ラベル14 pt、`cps-workshop` は本文16 pt・表14 ptを初期採用値とし、範囲外の自動縮小で救済しない。出典や番号は本文と異なる役割として検査する。

### 短い研究発表の視覚初期値

`cps-workshop` は10×5.625 inch、左右0.5 inchを基準に、通常題名24 pt、本文16 pt、問い28 pt、小見出し11 pt、表14 pt、出典8.5 pt、番号9 ptを採用する。値は全案件への下限ではなく、今回の投影条件と役割から採用範囲を記録する。長い題名はまず短文化と文節での改行を試し、全題名を縮小しない。

通常ページは題名右の正本ロゴ、題名下の細線、本文幅に揃えた下端線を使う。本文色 `#24302C`、表見出し面 `#F4F6F2`、強調面 `#EDF4E8`、比較面 `#F2F6ED` を役割として定義する。系列色は意味と入力の系列数から選び、ラベルや記号でも区別する。共通枠と内容レイアウトの数値はプロファイル・共通部品へ集約し、文書やページごとへ二重に手入力しない。

## 小さな左右ヘッダー・引用欄・最終サマリ

左右ヘッダー・引用・サマリは共通の役割。以下の座標は `cps-midterm` の基準であり、`cps-workshop` の採用位置はプロファイルから読む。研究内容・著者・所属・連絡先は今回の入力から得る。

### 左上の章タイトル・右上の発表タイトル

表紙以外で小さな共通ヘッダーを使う。10×5.625 inch基準で左は x=0.50, y=0.12, w=2.80, h=0.33、右は x=3.50, y=0.12, w=6.00, h=0.33。Noto Sans JP 10–12 pt、アクセントカラー、左揃え／右揃えを使う。右は記録済みの短縮発表タイトル、左は本文の現在の章名。目次・まとめ・補足・最終サマリはページ種別を左に出す。本文の大きなタイトルをこの小見出しに置き換えない。章扉の右上ロゴは y=0.55 inchを目安に下げ、右ヘッダーに重ねない。両型表紙では選択済みの表紙配置を維持する。

### 各ページ下部の参考文献と引用番号

主張・図の該当箇所に `[1]`、連番の複数引用なら `[1-4]`、非連番なら `[1,3]` を添え、そのページで用いた文献だけを下部に表示する。表記例は `[1] 著者, 短い文献名, 会議／誌名, 年.`。識別できる程度に短縮し、完全な書誌情報・DOI等はノートに保存する。引用番号はデッキ全体で固定し、同じ出典へ別番号を与えない。引用のないページは欄を空けてよく、不要な文献を付けない。

引用欄は x=0.50, y=4.62, w=9.00, h=0.36 inchを基準とし、8–10 pt、`SUBTEXT`、左揃え。フッターの線・ロゴ・ページ番号と重ねない。文献数が多い場合は主図の領域を減らして引用欄を広げ、読めないサイズに縮めたり引用を落としたりしない。横線なしの選択でも文献は残す。著者の一次結果と外部出典を区別し、未確認の書誌情報を作らない。

### サマリ（概要＋連絡先）

サマリの左上は「サマリ」、右上は短縮発表タイトル。本文上部に正式題目と著者・所属を置き、中央に発表の概要と主要な持ち帰り事項を2〜4点で示す。下部に使用者が指定した連絡先を置き、メール・URLは編集可能な文字と必要に応じてリンクにする。CPS LABの白背景・メイン／アクセント・ロゴ・選択式横線・必須ページ番号を使う。`cps-midterm` は補足後、`cps-workshop` は本編末尾を既定とし、引用があれば同じページ下部に文献を示す。補足後の再掲は別に選ぶ。QRコードは指定がある場合だけ使う。

`cps-midterm` の4行まとめは、重複する場合に使用者レビューでサマリと統合できる。`cps-workshop` は要点と議論したい問いを優先順位付きで示す。連絡先を表示するなら使用者指定のものを用い、省略指定なら省く。掲載希望なのに未提供の場合だけ確認し、架空の連絡先やプレースホルダーを残さない。

## 中間発表型の本文グリッド

座標・寸法はinch。題名を話題、主メッセージをその答えとして上部に置く。章名は左上の小見出しにのみ表示し、大きなタイトルや主メッセージへ重複して重ねない。内部MB番号は画面へ出さない。

| 領域 | x・y・幅・高さ | 役割 |
|---|---|---|
| タイトル | 0.50・0.52・9.00・0.43 | 話題が分かる短い題名 |
| 主メッセージ | 0.50・1.00・9.00・0.60 | 目的・結論を1文で示す |
| 主図・写真 | 0.50・1.72・9.00・2.44 | 下部の主役。図と写真の高さを揃える |
| 下部の補助領域（必要な場合） | 0.50・4.25・9.00・0.30 | 主図の簡潔なラベルと結論の理解に必要な条件。長い補足はメモへ |
| 短い出典・参考文献 | 0.50・4.62・9.00・0.36 | 本文とフッターをまたがない |
| フッター | y=5.045以降 | 選択式の下端線・左下ロゴ・必須の右下ページ番号 |

関連するラベルは対象へ寄せ、無関係な要素には0.18–0.25 inch程度の間隔を取る。正確な模式図は意味単位で編集可能にし、比較を通信・因果の矢印で描かない。実験図は正本データから作り、軸・単位・標本・条件・誤差表現を確認する。実機・評価写真は今回の正本素材を使い、実測値を生成画像へ描かせず、正本データを持つネイティブチャートで示す。

中心の問いや場面の切替を示すページは、上部の題名・メッセージ・下部の主図を毎回そろえず、大きな一文と余白を主役にできる。前提は前のページで整え、章名・短縮タイトル・番号・必要な出典の共通書式は保つ。原図の並置、章内の提案要約、既存イラストのタッチ継承の適用条件は [制作仕様](production.md) を参照する。

## 目次・章扉・関連研究・まとめ

### 画像付き2×2目次

上部に「目次」と短い全体案内、下部に4章を2×2で置く。左上01、右上02、左下03、右下04。各領域は章番号・章名・ページ範囲と、必要に応じて内容に対応する画像1枚。枠・影・角丸カードで囲わず、中央の薄い縦横線と余白で区切る。実物写真、評価場面、結果図、計画を示す概念図などを使い分け、計画画像には画像外へ「計画」と明記する。未提供の実証素材は生成で代用しない。

画像が説明に不要な研究や未提供の章では、画像を省き章名・ページ範囲・短い説明で示せる。空の素材枠や架空の実機画像を追加しない。章名の右側にはページ範囲の専用領域を確保する。

### 上部型の章扉

上部のキーカラー帯に章番号と目次と同じ章名、その下に短い案内文を置く。基準の帯は左0.50、上1.06、幅8.50、高さ0.90 inch。章名の左は0.73、案内文は左0.75・上2.31 inchを目安とする。帯上の文字は選択色の `ON_KEY_COLOR` を使う。右上ロゴを保ち、下部は広い白い余白にする。下寄りの色付き章名帯、左下ロゴ、下端線は置かない。ページ番号は右下へ置く。

### 関連研究

個別紹介では上部に研究名と要点、下部に引用図と自分の研究との違いを置く。研究名の下へ本文の細字を大量に貼らない。比較表の向きは読み方と文字量から決める。比較項目が少なければ研究を行、長い説明を並べるなら比較項目を行にする等、見出しと列幅を決める。何を比較しているかを見出しに書く。未実装の項目は「計画」として実装済みから区別する。短い出典をスライド上、詳細をノートへ置く。

### 縦4行のまとめ

上部は通常ページと同じ「まとめ」と主メッセージ。下部は左に章番号・章名、右に1〜2行の要約を置く4行。順序は目次・章扉と同じ。目安は左幅2.91 inch、間隔0.19 inch、右幅5.90 inch。行間には余白と薄い灰色の区切り線を置き、確認済みの結果と将来計画を文章で区別する。下部の大きな結論帯や角丸ボックスを足さない。通常フッターを使う。

## 表紙タイプA（type-a）

- 白背景。左上に今回の発表先・日付などを置く。元発表の名称・日時・発表者を残さない。
- 中央付近のキーカラー帯は左0.75、上1.55、幅8.50、高さ1.21 inchを目安にする。正式題目を `ON_KEY_COLOR` で2行以内、中央揃え。
- 下側の左に所属と発表者の灰色帯を2本、右に今回の研究対象・実機の写真1枚を置く。帯と写真を重ねず、写真の縦横比を守る。寸法は所属名と写真に合わせて調整する。
- 写真は対象を見せるために使い、通信波などを飾りとして足さない。表紙の写真を省略する場合はその判断と別ページの写真を記録し、デッキ全体の写真要件を満たす。未提供の実機写真を生成画像で代用しない。
- 共通フッター、左下ロゴ、右下ページ番号を使う。

## 表紙タイプB（type-b）

- 利用者が提供・指定した動画を16:9全画面に置く。背景の上に題目、所属、発表者などを中央揃えの白文字で重ねる。元の研究名や個人情報は引き継がない。
- 題目を中央より上、所属・発表者をその下へ置く。発表先・日付は上側。本文用の題目帯、灰色の所属帯、ロゴ、下端線は置かない。ページ番号は右下に必ず置き、動画より前面で読めるようにする。
- 原本を保持し、無音の派生動画を作る。背景動画は彩度90%・黒30%混合を初期値として、全尺で白文字を読めるよう調整する。色調の数値を映像ごとに無条件で固定しない。
- H.264 MP4を優先して埋め込み、同じ映像の静止ポスターを用意する。縦横比と再生速度を維持する。
- 表示時の自動再生、表紙中のループ、次ページへの遷移時停止、操作バー非表示を目標とし、対象アプリで確認する。静止画レンダーだけで再生検証済みと書かない。
- 動画を使えない環境では、静止ポスターへの変更を利用者と決める。GIF化や別サービスへのアップロードを勝手に行わない。
- 同梱の表紙見本は、未提供動画の配置を示す静止レイアウトであり、動画入り成果物ではない。
