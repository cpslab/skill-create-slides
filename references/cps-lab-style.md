# CPS LAB：中間発表型の構成・デザイン

## 適用と表紙の選択

このスキルの標準は、中間発表で用いた構成と本文デザイン。表紙だけ次の2種類から選ぶ。表紙の違いで本文・目次・章扉・まとめは変えない。ユーザーが明示した別テンプレートや修正範囲がある場合は、その指定を優先する。

| `COVER_STYLE` | 表示名 | 素材 | レイアウト |
|---|---|---|---|
| `type-a` | 表紙タイプA | 今回の研究対象・実機の写真 | 白背景、中央の題目帯、所属・発表者の灰色帯、右下の写真、共通フッター |
| `type-b` | 表紙タイプB | 今回の研究を示す背景動画と静止ポスター | 全画面動画、中央揃えの白文字、ロゴ・下端線なし、右下にページ番号 |

表示名は「表紙タイプA／表紙タイプB」、制作記録の `COVER_STYLE` は `type-a`／`type-b` に統一する。旧制作記録の `fit` は `type-a`、`midterm` は `type-b` として読み替え、選択済みなら聞き直さない。旧名は新しい選択肢として使用者へ提示しない。

初回に利用者の指定・現物を読み、選択がなければこの2択だけを確認する。本文の標準は質問し直さない。未回答時も企画書・本文構成を進められる。写真や動画が未提供なら必要な素材を具体的に伝え、無断で別の型へ変更しない。動画型を静止画にする場合は、その変更を利用者と決めて記録する。

## 任意の参考スライドで細部を調整する

参考スライドはCPS LAB全体を置き換えるテンプレートではなく、細部の調整に使う。実際の参照ページを見て、次の区別で適用する。

| 維持するCPS LABの基本 | 参考に寄せられる細部 |
|---|---|
| 16:9、白を基調とする本文、選択済みの表紙型 | 各ページ内の余白、整列、文章と図の占有比率 |
| 4章の流れ、必須目次・ページ番号、採用する章扉、縦4行のまとめ | 文字の組み方、改行、行間、太さ、強調、見出しと本文のサイズ比 |
| 正本ロゴと所定の扱い、上部の話題・メッセージと下部の主図という情報階層 | 補助色、淡色面、文字色、図表の系列色、強調色の使い分け |
| Noto Sans JPを基本とする文字体系、十分な可読性、編集可能性 | 図・写真の大きさ、位置、密度、注釈の置き方 |

キーカラーはCPS LABの色体系を軸に、参考の色相・明度・彩度・配色比率を取り入れる。本文全面を暗色にする、別組織のロゴへ交換する等の変更は、この細部調整には含めない。数値で定めた文字サイズ・図の寸法・配置は標準値とし、参考に合わせて調整する場合は今回の採用値と理由を記録する。読めないほどの小文字や低コントラストは模倣しない。

`style.md` に「参考資料のパス／URL・ページ」「寄せたい特徴」「維持するCPS要素」「採用した細部・具体的な値」「適用するスライド」を記録し、`slide-structure.org` の各ページ仕様へ反映する。複数の参考がある場合は対象ページや用途ごとに対応を決め、全体の色と文字階層を揃える。優先する参考が判断できない場合だけ使用者へ確認する。

## 標準の構成

表紙 → 必要に応じた研究の現在地 → 画像付き目次 → 01研究のねらい → 02しくみと評価方法 → 03ここまでの結果 → 04今後の展望 → まとめ → 補足（必要な場合） → 最終サマリ。

- 第1章では研究のねらい・問題・前提・今回の範囲を示し、関連研究を個別に紹介した後、同じ比較軸の表へまとめる。
- 各章の入口には章番号・章名・短い案内文を置く上部型の章扉を使う。関連研究に追加の区切りが必要なら同じ型を使う。
- 結果の解釈と限界は該当結果の近くへ置き、今後の具体的な設計・検証へ接続する。独立した議論章を自動追加しない。
- 目次とまとめの章名・順序を揃える。発表実績のない研究に学会名・採択実績を捏造しない。
- 枚数、研究名、関連研究名、図の数は今回の資料から決める。過去の46枚や特定の研究内容はテンプレートではない。

各色の見た目は [配色見本](palette-reference.md) とREADMEの各色1枚の画像で比較できる。

ベースカラーは白 `BACKGROUND`、メインは `KEY_COLOR`、アクセントはそれと異なる `ACCENT_COLOR` として常に定義する。ボタニカのアクセントは使用者指定の `#38761D`。他の5色は、その方針にならいメインより濃い同系色としてこのスキル用に設定したもので、元のCPS LAB資料から抽出した色ではない。

メインはまとまりを作る帯・面・線、アクセントは視線を集めたい重要語・数値・図の注目点に絞って使う。本文全体をアクセント色にせず、通常文字は `TEXT`、補足は `SUBTEXT` とする。アクセントの定義は必須だが、全ページへの強制使用や固定の面積比率は設けない。白背景上のアクセント文字とアクセント面上の文字はコントラストを確認し、淡いメイン面上では通常の濃色文字を基本にする。

`style.md` に3色のHEX値と用途を記録する。標準6色では上表を使い、別配色や参考資料による明示的な配色変更でも独立したアクセントを必ず選び、採用値・用途・可読性を記録して完成イメージでレビューする。

色名が未指定なら質問せずボタニカを使う。表にない指定はユーザーの明示変更として扱い、曖昧な場合だけ確認する。白地の強調文字には `ACCENT_COLOR` または濃い `TEXT` と太字を使い、薄いメインカラーの文字へ一律変更しない。系列は記号・線種・ラベルでも区別し、図固有の意味色は保つ。

16:9、基準10×5.625 inch（720×405 pt）。13.333×7.5 inchでは位置・寸法・文字サイズを4/3倍する。描画APIのpxとptを混同しない（96 px = 72 pt）。フォントはNoto Sans JP、代替はSawarabi Gothic。代替使用は記録する。ページ番号はArial。細いウェイト、強い影、立体・光彩・装飾的なカード列は使わない。

| 要素 | 基準サイズでの文字 | 配置・量 |
|---|---|---|
| 表紙題目 | 28–32 pt、太字 | 2行以内、中央揃え |
| 表紙情報 | 16–18 pt | 発表先、日付、所属、発表者 |
| 通常タイトル | 26–30 pt、太字 | 原則1行、左揃え |
| 主メッセージ | 22–26 pt、太字 | 最大2行、左揃え |
| 章扉の章名 | 36–40 pt、太字 | 上部のキーカラー帯に章番号と並べる |
| 章扉の案内文 | 22–26 pt | 章名の下に短く1文 |
| 本文 | 18–22 pt | 左揃え、長文を置かない |
| 図ラベル | 14–18 pt | 対象に寄せ、図とともに読める大きさ |
| 重要条件・主要数値 | 18–22 pt | 小さい出典文字へ追い込まない |
| 出典 | 8–10 pt | 図の直下または本文の最下部 |
| ページ番号 | 14 pt | 右下 |

収まらないときは本文を縮めず、短文化・補足への移動・MBの分割を検討する。本文18 pt、図ラベル14 ptを下回らない。

## 小さな左右ヘッダー・引用欄・最終サマリ

この追加仕様は、提供された研究発表PDFの通常ページと最終ページを配置の参考にしたもの。参考の研究内容・著者・所属・連絡先・ロゴをスキルへコピーせず、CPS LABの配色と正本ロゴを保って適用する。

### 左上の章タイトル・右上の発表タイトル

表紙以外で小さな共通ヘッダーを使う。10×5.625 inch基準で左は x=0.50, y=0.12, w=2.80, h=0.33、右は x=3.50, y=0.12, w=6.00, h=0.33。Noto Sans JP 10–12 pt、アクセントカラー、左揃え／右揃えを使う。右は記録済みの短縮発表タイトル、左は本文の現在の章名。目次・まとめ・補足・最終サマリはページ種別を左に出す。本文の大きなタイトルをこの小見出しに置き換えない。章扉の右上ロゴは y=0.55 inchを目安に下げ、右ヘッダーに重ねない。両型表紙では選択済みの表紙配置を維持する。

### 各ページ下部の参考文献と引用番号

主張・図の該当箇所に `[1]`、連番の複数引用なら `[1-4]`、非連番なら `[1,3]` を添え、そのページで用いた文献だけを下部に表示する。表記例は `[1] 著者, 短い文献名, 会議／誌名, 年.`。識別できる程度に短縮し、完全な書誌情報・DOI等はノートに保存する。引用番号はデッキ全体で固定し、同じ出典へ別番号を与えない。引用のないページは欄を空けてよく、不要な文献を付けない。

引用欄は x=0.50, y=4.62, w=9.00, h=0.36 inchを基準とし、8–10 pt、`SUBTEXT`、左揃え。フッターの線・ロゴ・ページ番号と重ねない。文献数が多い場合は主図の領域を減らして引用欄を広げ、読めないサイズに縮めたり引用を落としたりしない。横線なしの選択でも文献は残す。著者の一次結果と外部出典を区別し、未確認の書誌情報を作らない。

### 最終サマリ（概要＋連絡先）

最終ページの左上は「サマリ」、右上は短縮発表タイトル。本文上部に正式題目と著者・所属を置き、中央に発表の概要と主要な持ち帰り事項を2〜4点で示す。下部に使用者が指定した連絡先を置き、メール・URLは編集可能な文字と必要に応じてリンクにする。CPS LABの白背景・メイン／アクセント・ロゴ・選択式横線・必須ページ番号を使う。補足の後へ置き、引用があれば同じページ下部に文献を示す。参考PDFにあるQRコードや別組織のロゴは必須にしない。

本編末尾の4行まとめは維持でき、重複する場合は使用者レビューで最終サマリと統合する。その場合も4章の振り返りと概要・著者の連絡先を含め、最終ページに置く。連絡先が未提供なら入力票へ未確認として記録し、使用者に確認する。最終納品に架空の連絡先や入力用プレースホルダーを残さない。

## 本文のグリッド

座標・寸法はinch。題名を話題、主メッセージをその答えとして上部に置く。章名は左上の小見出しにのみ表示し、大きなタイトルや主メッセージへ重複して重ねない。内部MB番号は画面へ出さない。

| 領域 | x・y・幅・高さ | 役割 |
|---|---|---|
| タイトル | 0.50・0.52・9.00・0.43 | 話題が分かる短い題名 |
| 主メッセージ | 0.50・1.00・9.00・0.60 | 目的・結論を1文で示す |
| 主図・写真 | 0.50・1.72・9.00・2.44 | 下部の主役。図と写真の高さを揃える |
| 下部の補助領域（必要な場合） | 0.50・4.25・9.00・0.30 | 主図の簡潔なラベル等。誤解防止の注意書き・限定・条件列挙で埋めない |
| 短い出典・参考文献 | 0.50・4.62・9.00・0.36 | 本文とフッターをまたがない |
| フッター | y=5.045以降 | 選択式の下端線・左下ロゴ・必須の右下ページ番号 |

関連するラベルは対象へ寄せ、無関係な要素には0.18–0.25 inch程度の間隔を取る。正確な模式図は意味単位で編集可能にし、比較を通信・因果の矢印で描かない。実験図は正本データから作り、軸・単位・標本・条件・誤差表現を確認する。実機・評価写真は今回の正本素材を使い、実測値を示す画像をImageGenで生成しない。

## 目次・章扉・関連研究・まとめ

### 画像付き2×2目次

上部に「目次」と短い全体案内、下部に4章を2×2で置く。左上01、右上02、左下03、右下04。各領域は章番号・章名と、内容に対応する画像1枚。枠・影・角丸カードで囲わず、中央の薄い縦横線と余白で区切る。実物写真、評価場面、結果図、計画を示す概念図などを使い分け、計画画像には画像外へ「計画」と明記する。未提供の実証素材は生成で代用しない。

### 上部型の章扉

上部のキーカラー帯に章番号と目次と同じ章名、その下に短い案内文を置く。基準の帯は左0.50、上1.06、幅8.50、高さ0.90 inch。章名の左は0.73、案内文は左0.75・上2.31 inchを目安とする。帯上の文字は選択色の `ON_KEY_COLOR` を使う。右上ロゴを保ち、下部は広い白い余白にする。下寄りの色付き章名帯、左下ロゴ、下端線は置かない。ページ番号は右下へ置く。

### 関連研究

個別紹介では上部に研究名と要点、下部に引用図と自分の研究との違いを置く。研究名の下へ本文の細字を大量に貼らない。最後の比較表は比較項目を行、対象研究を列にし、何を比較しているかを見出しに書く。未実装の項目は「計画」として実装済みから区別する。短い出典をスライド上、詳細をノートへ置く。

### 縦4行のまとめ

上部は通常ページと同じ「まとめ」と主メッセージ。下部は左に章番号・章名、右に1〜2行の要約を置く4行。順序は目次・章扉と同じ。目安は左幅2.91 inch、間隔0.19 inch、右幅5.90 inch。行間には余白と薄い灰色の区切り線を置き、確認済みの結果と将来計画を文章で区別する。下部の大きな結論帯や角丸ボックスを足さない。通常フッターを使う。

## 表紙タイプA（type-a）

- 白背景。左上に今回の発表先・日付などを置く。元発表の名称・日時・発表者を残さない。
- 中央付近のキーカラー帯は左0.75、上1.55、幅8.50、高さ1.21 inchを目安にする。正式題目を `ON_KEY_COLOR` で2行以内、中央揃え。
- 下側の左に所属と発表者の灰色帯を2本、右に今回の研究対象・実機の写真1枚を置く。帯と写真を重ねず、写真の縦横比を守る。寸法は所属名と写真に合わせて調整する。
- 写真は対象を見せるために使い、通信波などを飾りとして足さない。写真が不要・用意できない場合は省略の判断を記録し、架空の実機を生成しない。
- 共通フッター、左下ロゴ、右下ページ番号を使う。

## 表紙タイプB（type-b）

- 利用者が提供・指定した動画を16:9全画面に置く。背景の上に題目、所属、発表者などを中央揃えの白文字で重ねる。元の研究名や個人情報は引き継がない。
- 題目を中央より上、所属・発表者をその下へ置く。発表先・日付は上側。本文用の題目帯、灰色の所属帯、ロゴ、下端線は置かない。ページ番号は右下に必ず置き、動画より前面で読めるようにする。
- 原本を保持し、無音の派生動画を作る。背景動画は彩度90%・黒30%混合を初期値として、全尺で白文字を読めるよう調整する。色調の数値を映像ごとに無条件で固定しない。
- H.264 MP4を優先して埋め込み、同じ映像の静止ポスターを用意する。縦横比と再生速度を維持する。
- 表示時の自動再生、表紙中のループ、次ページへの遷移時停止、操作バー非表示を目標とし、対象アプリで確認する。静止画レンダーだけで再生検証済みと書かない。
- 動画を使えない環境では、静止ポスターへの変更を利用者と決める。GIF化や別サービスへのアップロードを勝手に行わない。
- 同梱の表紙見本は、未提供動画の配置を示す静止レイアウトであり、動画入り成果物ではない。

## ロゴ・フッター

下端のメインカラー横線は `FOOTER_LINE: on / off` で選ぶ。新規制作で未指定なら使用者に「あり／なし」を確認し、確定値を記録する。`on` は下表の通常フッター対象に線を表示、`off` はその線のみ省略する。章扉・表紙タイプBは元の線なしを保つ。線の色は `KEY_COLOR`（メインカラー）とし、アクセントカラーへ置き換えない。ロゴ・ページ番号・余白は維持する。

正本は [NewmajimeModeLogoSmall.png](../assets/NewmajimeModeLogoSmall.png)、438×123 px。変形、切り抜き、再着色、透明度変更、影付けをしない。周囲には少なくとも0.15 inchの余白を保つ。

| 種類 | ロゴ・線・ページ番号 |
|---|---|
| 本文・目次・まとめ・補足・最終サマリ・表紙タイプA | ロゴ：左0.321・上5.253・幅0.895 inch。下端線：`FOOTER_LINE=on` の場合のみ、上5.045・高さ0.059 inch、色 `KEY_COLOR`。ページ番号：右下 |
| 章扉 | ロゴ：左8.418・上0.55・幅1.211 inch。左下ロゴと下端線なし。ページ番号は右下 |
| 表紙タイプB | ロゴ・下端線なし。ページ番号は右下、動画より前面 |

出典はフッターのロゴやページ番号へ重ねない。通常ページと章扉のロゴを1枚へ重複配置しない。

## 最終確認
