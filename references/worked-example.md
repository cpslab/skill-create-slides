# 通し作例：架空の室内環境ログ研究

**以下は全て架空の教材。数値は合成データであり、実測結果ではない。** 完成文章や研究テーマを流用するためではなく、根拠を各工程へ引き継ぐ方法を示す。入力は [example-source.org](../assets/example-source.org) に全て含まれる。実際の制作では本人の資料・言葉・発表条件へ置き換える。

## 1. 入力と今回のスタイルを決める

架空の条件は「専門外もいる研究室の4分報告」。13点の合成系列から3点だけを保持する処理を扱う。入力E1、計算結果E2、計画P1、未確認U1を区別する。過去チャットへのアクセスは不要。

スタイルは中間発表型CPS。16:9、白背景、Noto Sans JP、ボタニカ、上部のタイトル・主メッセージと下部の主図・短い条件注記を使う。この教材ではFIT2026型表紙を選び、実機写真は入力にないため省略すると決めたものとする。4分という制約に合わせ、目次と章扉は省略した短縮例で、4章の読み順は保持する。表紙＋4章各1枚＋縦4行のまとめの計6枚を想定し、架空例である旨を表紙と定量図に表示する。通常の構成と2種類の表紙は視覚レイアウト見本を参照する。

## 2. 企画書に変換する（架空例）

| 要素 | 入力から書けること |
|---|---|
| 世界観：現状 | 記録点を減らす方法を検討しているが、短い変化が残るかは未確認。社会全体の状況へ一般化しない |
| 世界観：理想 | 必要な変化を読み取れる環境ログを、用途に合う記録量で残したい |
| 世界観：課題 | 今回は一つの合成系列で、間引きにより失われる情報を確認する |
| 世界観：障害 | 記録点の数だけでは、保持される変化を判断できない |
| 作戦A | **同じ合成系列の間引きによる、保持情報の比較**。全13点と0・5・10分の3点を比べ、保持点数・最大値・閾値超過点の有無を見る（E1） |
| 成果A：結果 | 13点から3点に減り、保持最大値は1120から970 ppmへ変化した。1000 ppm超の記録点は2点から0点になった（E2） |
| 成果A：知見 | この系列と開始時刻では、5分間隔の記録に短時間の高い値が残らなかった |
| 成果A：考察 | 記録量と、残したい変化の時間的な細かさを併せて検討する必要がある |
| 教訓・Main findings | **記録点を減らす検討では、残る変化を同じ入力上で確かめる。** 今回確認したのは一つの合成例であり、次に波形・開始時刻・実機条件を変える（P1） |

目的→方法→結果は「短い変化が残るか」→「同じ系列を間引いて比較」→「この条件では高い値が残らなかった」と対応する。電力と人の理解は測っていないため、この対応へ混ぜない。

| 悪い主張（架空例） | 証拠に合う主張（架空例） | 直す理由 |
|---|---|---|
| 5分間隔では室内の異常を見逃す | この合成系列では、5分間隔の保持点に1000 ppm超の値が残らなかった | 実環境・異常検出は未検証。閾値は教材用 |
| 記録点を減らして省電力化できた | 保持点数が13点から3点に減った | 消費電力を測っていない |
| 1分間隔が最適である | 今回の全13点には短時間の高い値が含まれる | 他の間隔、開始時刻、用途を比較していない |

## 3. 3項目のMBへ分解する（架空例）

短時間報告なので独立した章扉は置かず、章名は制作記録で使う。下記は中間発表型の4章に対応する本編4MBの全体。出典対応はコードブロックの外に保持する。

```org
* 研究のねらい
** MB-01 今回の問い
- 話題 :: 記録点を減らす検討
- メッセージ :: 記録点数と、残る変化を併せて確かめたい。
- 補足 :: 一つの合成系列を使う予備検討の範囲を示す。
* しくみと評価方法
** MB-02 比較方法
- 話題 :: 同じ入力の間引き
- メッセージ :: 全13点と、0・5・10分の3点を比較した。
- 補足 :: 同じ横軸上で保持する点を示し、比較項目を添える。
* ここまでの結果
** MB-03 保持された情報
- 話題 :: 短時間の高い値
- メッセージ :: この合成例では、5分間隔の保持点に高い値が残らなかった。
- 補足 :: 2系列と任意閾値を重ね、最大値1120／970 ppmを示す。
* 今後の展望
** MB-04 次に確かめること
- 話題 :: 記録間隔の検討方法
- メッセージ :: 記録点を減らす際は、残したい変化も同じ入力上で確かめる。
- 補足 :: 今回の一例という範囲と、波形・開始時刻・実機条件を変える計画を示す。
```

根拠対応：MB-01＝問い、MB-02＝E1、MB-03＝E2、MB-04＝E2に基づく考察＋P1。MB-04の一般的な助言を、実証済みの最適設計指針とは呼ばない。目安は表紙10秒＋本編30／50／70／45秒＋まとめ25秒＝230秒で、10秒の余裕を残す。読み上げで再調整する。

## 4. スライド仕様へ具体化する（架空の結果ページ）

```org
** S03 保持された情報
- 対応MB :: MB-03
- タイトル :: 記録に残った値の違い
- メインメッセージ :: この合成例では、5分間隔の保持点に高い値が残らなかった。
- 載せる内容 :: 2系列の比較図、最大値1120／970 ppm、合成データの表示。
- 図形・図表の詳細 ::
  - 共通横軸0〜12分、共通縦軸600〜1200 ppmの散布図。
  - 全13点は濃い灰色の小さい丸。保持3点は強調色の大きい四角。
  - 1000 ppmに破線。「説明用の任意閾値」と明記。
  - 6分の1120 ppmと5分の970 ppmに短いラベル。線やラベルを重ねない。
  - 図の下に「架空例・合成データ／開始時刻0分／実機検証は未実施」。
- 作成手段・素材 :: 入力表からネイティブ散布図。タイトル・注記は編集可能な文字。
```

MB-01→S01、MB-02→S02、MB-03→S03、MB-04→S04。表紙と4章の要約を並べるまとめは別管理。結果図はデータから作り、ImageGenへ数値の再現を任せない。実環境写真は入力にないため加えない。

## 5. 完成イメージ用プロンプトの抜粋（架空例）

> 編集可能PPTXの制作前に検討する、架空研究のデザインラフを作成する。FIT2026型表紙＋S01〜S04＋縦4行のまとめの計6枚を、上段3枚・下段3枚に左から右へ配置。各ページ16:9の正面平面図、中間発表型の白背景・Noto Sans JP・ボタニカ・均一な余白。表紙に「架空研究・合成データの作例」。S01は問い、S02は13点から3点を保持する模式図、S03は提供する正本グラフ画像の配置検討、S04は確認済みの範囲と次の計画を示す。S03の図と数値を新しく描き直さず、同じ入力から作った参照図の位置と大きさを検討する。ロゴは指定の正本を所定位置へ置き、実証写真は加えない。まとめは4章と同順で左に章名・右に要約を4行で配置する。内部MB番号は画面へ出さない。日本語本文の正本は構成ファイルに置く。

この抜粋は生成結果ではない。実行時は各ページの確定仕様と正本グラフを添付し、プロンプト・入力・出力・対応版を保存する。生成画像が図を変形した場合も結果の根拠へ使わず、最終PPTXには正本データから作った図を配置する。

## 6. PPTXへ移し、同じ基準で確認する（架空例）

| 対象 | 実装と検証証拠 |
|---|---|
| 言葉と数値 | 企画書・MB・構成・PPTXでE1/E2との対応を照合。全ての定量ページに合成データと表示 |
| 図表 | ネイティブ散布図の埋込データが13点／3点であることを確認。任意閾値を安全基準と呼ばない |
| 編集可能性 | タイトル・注記・模式図の要素が個別に編集でき、チャートのデータ編集ができるか確認 |
| 見た目 | 出力PPTXを全6ページ再レンダーし、1枚ずつ文字・軸・ラベル・余白を確認。ラフだけの確認で終わらない |
| 完成の記録 | 実際に行った検証の方法・結果・未実施項目を記録。教材を読んだだけで「検証済み」としない |

研究内容が変わっても引き継ぐのは、根拠の境界・工程間の対応・編集可能性・全ページの視覚確認。この短縮例の枚数、章の時間配分、グラフ形式や数値は固定ルールではない。
