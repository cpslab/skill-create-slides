写真・動画・目次画像の配置枠は、レイアウトを説明する教材の一部。実際の納品物には未置換のまま残さない。研究内容の不足を実証写真や実動画の生成で埋めない。

画像だけで比較せず、PPTXのテキスト・図形・表・チャートを選択して編集可能性も確かめる。合成数値・架空発表者・教材注記は今回の研究内容へ置き換える。チャートや表の形式は今回の根拠に合わせる。

キャンバスは960×540 px（10×5.625 inch）。これは16:9の実装基準。文字サイズのpxとptを区別する（96 px = 72 pt）。別サイズへ移す場合は位置・寸法・文字階層を整合させる。配色は [スタイル仕様](cps-lab-style.md) の6色と文字色の対応を使う。

## 検証範囲

2026-10-07の1.4.1版で最終PPTXを再読み込みした全9枚を目視し、構造・表・チャートの埋込数値と合成入力を照合した。1.4.2以降の表紙名変更では全9枚の表示画像が検証済み版と画素単位で一致することを確認した。PowerPoint本体での編集・再保存は未検証。表紙の動画は同梱していないため、動画再生も未検証である。

PNG描画エンジンでは、散布図の四角点が丸、破線が実線として表示される。PPTX内部には指定した形状と線種が残っている。作例は点の大きさと凡例も併用して条件を区別する。各メンバーの発表用アプリでの表示と動作を別に確認する。

配布版とファイルの対応は [パッケージ記録](../package-manifest.json) を参照する。実案件では、選んだ表紙の素材・自動再生・ループ・無音・次ページでの停止、全ページの表示・編集の実施範囲を制作記録へ残す。

## 作例を再生成するとき

通常の利用に再生成は不要。現行 `Presentations` スキルと `load_workspace_dependencies` で必要な環境を確認し、実際の絶対パスを設定する。

| 変数 | 内容 |
|---|---|
| `RUNTIME_NODE` | 同梱Node.jsの実行ファイル |
| `RUNTIME_NODE_MODULES` | `@oai/artifact-tool` と `sharp` がある同梱パッケージディレクトリ |
| `RUNTIME_PYTHON` | 同梱Pythonの実行ファイル |
| `PRESENTATIONS_SKILL_DIR` | 現在利用するPresentationsスキルのディレクトリ |
| `VISUAL_BUILD_DIR` | 新しい作業用ディレクトリ。既存納品物を含めない |
| `RESEARCH_SLIDE_SKILL_DIR` | この研究発表スキルのディレクトリ |

現行Presentationsの制作開始・実装手順に従って実行する。

```bash
"$RUNTIME_NODE" "$RESEARCH_SLIDE_SKILL_DIR/assets/visual-reference/build.mjs"
```

出力は `VISUAL_BUILD_DIR/output/`、候補と検証記録は同ディレクトリ内の `.build/`。既存納品名がある作業先へ上書きしない。コードはスキル内の合成入力表を読むためフォルダ構成を維持する。実案件用にする場合は、固定された9種類の見本・合成値の検査・素材枠を意図的に置き換える。

見本はボタニカのメイン色 `#9BBB59` と独立アクセント `#38761D` を使う。表紙以外には左右の小さなヘッダー、入力資料を使用するページには `[1]` と同じページ下部の出典を表示する。全9枚に表示順のページ番号を付ける。

再生成時は `FOOTER_LINE=on` または `off` で下端線を切り替える（教材の既定値は `on`）。章扉と表紙タイプBには線を置かず、`off` でもロゴとページ番号は残す。実案件では利用者の選択を記録する。

この一覧PNGは最終PPTXの検証用レンダーをまとめた画像であり、ImageGenによる完成イメージではない。実案件の完成イメージは必ずImageGenで全ページを1枚に生成し、使用者のレビューを受ける。
